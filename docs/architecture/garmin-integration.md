# Интеграция Garmin

## Цель первого этапа

Получить официально поддерживаемое подключение Garmin-аккаунта. Импорт Activity data относится ко второму этапу.

## Источник требований

Реализация должна опираться на документацию Garmin Connect Developer Program, доступную после одобрения приложения. До доступа разрешена только разработка адаптера и тестового mock flow; предположения о scopes, endpoints, token lifetime, refresh/revoke и webhooks нельзя выдавать за подтверждённые требования.

## Поток подключения

1. Авторизованный пользователь начинает подключение.
2. Backend формирует запрос авторизации с одноразовым, ограниченным по времени `state`.
3. Пользователь даёт согласие на стороне Garmin.
4. Backend валидирует callback и обменивает code на сервере.
5. Подключение связывается с текущим пользователем, токены шифруются.
6. UI показывает актуальный статус.

## Статусы

Минимально: `pending`, `connected`, `reconnect_required`, `disconnected`, `error`. Модель может быть уточнена после изучения Garmin error/revoke semantics.

## Открытые вопросы после доступа в Developer Portal

- точный протокол и обязательные параметры авторизации;
- scopes для Activity API;
- lifetime и rotation токенов;
- способ отзыва и уведомления о deauthorization;
- callback URLs для разных окружений;
- rate limits и production approval;
- branding и consent requirements.
