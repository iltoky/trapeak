# v0.11.0

Статус: **Ready for production publication; authenticated e2e deferred**

## Что изменилось

- Лендинг теперь показывает полный рабочий цикл: запись через один AI, анализ или планирование через другой AI и работа с реальным специалистом.
- Добавлены пять фактических use-case страниц с примерами диалогов, стартовыми вопросами, границами данных и FAQ.
- Публичная модель доступа ограничена тремя понятными категориями: Training, Nutrition и Health.
- Recovery не рекламируется как доступная категория: sleep, HRV и recovery остаются недоступными до подключения датированного источника.
- Dashboard разделён на Overview, Training, Nutrition, Health, Shared access и Connections.
- Nutrition показывает дневные итоги и раскрываемые дни вместо одной длинной ленты приёмов пищи.
- Shared access получил более понятную выдачу разрешений по email без ролей, с expiry, revoke и audit trail.

## SEO и обнаружение

- Обновлены metadata, Open Graph image, JSON-LD, sitemap, robots и `llms.txt`.
- В sitemap добавлены только работающие use cases; плановые Garmin-страницы исключены из индексации до появления интеграции.
- Приватные account, access, API, MCP и auth маршруты закрыты от поисковых роботов.

## Безопасность и совместимость

- `/access` и `/api/access` включены в обязательный auth boundary proxy.
- API создания нового grant принимает только текущие assignable-категории.
- Зарезервированное значение `recovery` сохранено в backend-модели для совместимости с применённой migration.
- Authenticated end-to-end тестирование остаётся отдельным этапом по ранее согласованному решению.
