# v0.6.0

Статус: **Candidate; production migrations applied**

Дата: **13 августа 2026**

## AI Nutrition

- Добавлен MCP-инструмент `create_nutrition_entry` для записи приёма пищи после явной команды пользователя.
- Одна запись хранит исходное описание, суммарные Kcal/P/C/F, время, тип приёма пищи и допущения AI-оценки.
- Идемпотентный повтор tool call не создаёт дубль.
- Dashboard больше не предлагает ручной ввод; он показывает дневной итог и последние записи.

## Laboratory results

- Добавлены отчёты для blood, urine, stool, saliva и other.
- Каждый отчёт хранит дату забора, лабораторию, заметку и структурированные показатели со значением, единицей, референсом и флагом.
- Добавлены MCP-инструменты `create_lab_report`, `list_lab_reports`, `get_lab_report` и `get_lab_result_history`.
- TRAPEAK хранит данные как переданные и не ставит диагноз; PDF/OCR отложены на отдельный этап.

## Database

- `0004_ai_nutrition.sql` расширяет nutrition без нарушения совместимости со старой схемой.
- `0005_labs.sql` добавляет лабораторные отчёты и результаты с user scoping и идемпотентностью.
- Обе production migrations подтверждены владельцем до публикации приложения.
