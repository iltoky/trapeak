# v0.2.0

Статус: **Ready to publish**

Дата подготовки: **13 августа 2026**

Production deployment: **не выполнен**

Публикация выполняется напрямую в `main` по main-only workflow после подготовки production Wahoo configuration и миграции БД.

## Изменения

- Включены все изменения непубликованного candidate `v0.1.1`: мобильное меню, release workflow, Wahoo OAuth foundation и Vercel Speed Insights.
- Реальное Wahoo OAuth-подключение успешно подтверждено в Preview.
- Добавлено получение нормализованного Wahoo athlete profile.
- Добавлена ручная синхронизация 30 последних workout records; в историю попадают только завершённые записи с `workout_summary`.
- Профиль, нормализованные activity fields, raw provider payload и sync state сохраняются в PostgreSQL.
- Повторная синхронизация идемпотентна по provider activity ID.
- Добавлен refresh access token непосредственно перед API-вызовом и атомарное сохранение rotating token pair.
- Disconnect корректно обрабатывает уже недоступный provider access и очищает локальные токены.
- Dashboard показывает только connection/sync status и число сохранённых тренировок, без аналитического интерфейса.

## Известные ограничения

- Первый ручной импорт ограничен 30 последними Wahoo workout records.
- Webhooks, удаление provider activities и фоновая догрузка истории ещё не реализованы.
- Wahoo не возвращает завершённые тренировки, которые исходно поступили в Wahoo из сторонних приложений.
