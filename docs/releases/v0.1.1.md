# v0.1.1

Статус: **Release candidate**

Дата подготовки: **13 августа 2026**

Production deployment: **не выполнен**

## Изменения

- `Sign in` и `Create account` в мобильном меню размещены отдельными строками и занимают полную ширину.
- Авторизованное состояние dashboard использует ту же вертикальную компоновку для `Account` и профиля Clerk.
- Добавлен формальный двухэтапный процесс релизов: подготовка release candidate и отдельная публикация после подтверждения.
- Добавлен каталог release notes и версия приложения обновлена до `0.1.1`.
- Добавлена основа server-side Wahoo OAuth adapter: authorization URL, token exchange, refresh, profile и revoke.
- Конфигурация Wahoo закрывается ошибкой при отсутствии server-only credentials; scopes зафиксированы по официальной документации.
- Roadmap и инструкции обновлены под Wahoo-first реализацию, Garmin сохранён в статусе planned/soon.
- Добавлены защищённые Wahoo Connect/Callback/Disconnect routes и отображение connection status в dashboard.
- Добавлены PostgreSQL migration, server-only repository и authenticated encryption provider tokens.
