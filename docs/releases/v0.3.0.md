## Результат

- Добавлен authenticated read-only remote MCP по `/mcp`.
- Clerk используется как OAuth 2.1 authorization server без отдельной identity системы.
- Добавлены `get_athlete_profile`, `list_activities` и `get_activity`.
- Все MCP-запросы ограничены данными OAuth-пользователя.
- Raw provider payload и внутренние identifiers не возвращаются MCP-клиентам.
- Сообщение Wahoo sync теперь различает received, new, updated и stored workouts.
- Этап Wahoo ingestion закрыт после реальной production-проверки без дублей.
