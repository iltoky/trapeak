# Правила выполнения задач Claude

Для каждой задачи Claude должен:

1. Прочитать связанные страницы Wiki и проверить текущий код.
2. Не расширять scope без отдельного решения.
3. Если задача заблокирована внешним доступом, реализовать только явно разрешённый mock/adapter и отметить блокер.
4. Добавить или обновить тесты и документацию.
5. Запустить lint, typecheck, tests и build, доступные проекту.
6. В результате перечислить изменённые файлы, проверки, допущения и оставшиеся блокеры.

Одна задача должна выполняться отдельным PR. Секреты, реальные токены и персональные данные запрещено добавлять в код, fixtures и логи.
