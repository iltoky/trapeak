# TRAPEAK

TRAPEAK — персональный аналитик тренировок, который получает данные пользователя из Garmin и делает их доступными AI-ассистентам через единый MCP-интерфейс.

Главная ценность продукта: превратить тренировочные данные в понятные ответы на вопросы «что со мной происходит?», «есть ли прогресс?» и «что делать дальше?».

## Технический MVP

1. Авторизация пользователя и подключение Garmin.
2. Получение, нормализация и хранение тренировок Garmin.
3. Read-only MCP-сервер для Claude и ChatGPT.

Собственный аналитический дашборд, тренировочные планы и AI-чат внутри TRAPEAK не входят в технический MVP.
