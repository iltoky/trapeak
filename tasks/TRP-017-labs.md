# TRP-017 — Labs / Blood Tests

Статус: **Published; authenticated production e2e passed**

## Описание

Хранить структурированные лабораторные отчёты и показатели пользователя, предоставлять историю через MCP и позволять владельцу безопасно удалить ошибочно сохранённый отчёт.

## Acceptance criteria

- AI после явной команды сохраняет отчёт с датой, типом материала, названием, лабораторией и заметкой.
- Каждый показатель хранит исходное название, текстовое и при наличии числовое значение, единицу, референс и флаг лаборатории.
- Повторная запись идентичного отчёта идемпотентна и не создаёт дубль.
- `list_lab_reports`, `get_lab_report` и `get_lab_result_history` возвращают только данные текущего пользователя.
- `delete_lab_report` удаляет только отчёт владельца и каскадно удаляет его показатели.
- Удаление через MCP требует конкретного report ID и явного `confirm: true`; dashboard запрашивает подтверждение.
- TRAPEAK не придумывает отсутствующие значения и не ставит диагноз.
