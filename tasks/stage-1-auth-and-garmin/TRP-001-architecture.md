# TRP-001 — Зафиксировать архитектуру и стек

## Description

Принять и документировать решения, необходимые для разработки: runtime/framework, PostgreSQL, ORM и миграции, пользовательская авторизация, тестовый стек, структура модулей, управление конфигурацией и deployment target. Создать ADR и актуализировать архитектурную Wiki.

Кандидат по умолчанию: TypeScript, Next.js, PostgreSQL, Auth.js, Docker Compose. Prisma и Drizzle сравнить кратко и выбрать один.

## Acceptance Criteria

- ADR содержит контекст, рассмотренные варианты, решение и последствия.
- Зафиксированы версии/runtime policy и структура репозитория.
- Описаны границы `auth`, `users`, `integrations/garmin`, `db`, `config`.
- Подтверждено: Garmin вызывается только сервером; пользовательские токены хранятся в БД зашифрованно.
- Открытые решения не маскируются под принятые.
