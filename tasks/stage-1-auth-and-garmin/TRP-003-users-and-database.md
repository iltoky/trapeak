# TRP-003 — Настроить БД и модель пользователя

## Description

Подключить PostgreSQL и миграции. Создать минимальную модель пользователя и таблицы, требуемые выбранной auth-библиотекой. Использовать внутренний ID, нормализованный уникальный email и timestamps.

## Acceptance Criteria

- Схема воспроизводится миграциями на пустой БД.
- Пользователь создаётся и находится по внутреннему ID.
- Нормализованный email уникален.
- Миграции и схема хранятся в Git.
- Seed не содержит production-пользователей и персональных данных.
- Repository/service tests покрывают основные ограничения.

## Release Actions

Применить миграции до запуска версии приложения, которая использует схему.

## Testing Recommendations

Проверить apply migrations на чистой БД и повторный запуск без изменений.

## QA e2e tests

Не требуется до реализации auth UI.
