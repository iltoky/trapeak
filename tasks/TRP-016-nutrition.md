# TRP-016 — Nutrition journal and MCP

Статус: **In progress**

## Описание

Добавить пользовательский журнал питания с ручным вводом калорий и макронутриентов. Данные доступны только владельцу в dashboard и подключённым им MCP-клиентам.

## Acceptance criteria

- Пользователь может сохранить приём пищи с датой/временем, типом, названием, калориями, белками, углеводами, жирами и необязательной заметкой.
- Сервер валидирует длину и числовые диапазоны независимо от browser validation.
- Пользователь видит последние записи и дневные итоги, а удалить может только собственную запись.
- MCP предоставляет read-only `list_nutrition_entries` и `get_nutrition_summary`.
- Все запросы к БД обязательно ограничены текущим Clerk user ID.
- Nutrition описывается как пользовательский журнал, а не медицинская рекомендация.

## Release actions

1. Применить `0003_nutrition.sql` к production БД до публикации кода.
2. Проверить ручное добавление и удаление записи в production dashboard.
3. В developer-mode клиенте вызвать оба новых MCP-инструмента.

## QA e2e tests

1. [ ] Добавление корректного meal создаёт одну запись.
2. [ ] Некорректные и отрицательные значения отклоняются.
3. [ ] Дневные итоги равны сумме записей соответствующего UTC-дня.
4. [ ] Пользователь не может удалить чужую запись.
5. [ ] MCP-фильтры по датам и meal type возвращают только данные текущего пользователя.
